# オントロジーカタログ日本語化 実装計画

> Issue: #15

## 目的

カタログ画面の固定UI、状態表示、アクセシブル名、表示用カテゴリ名を日本語化する。カタログ由来の値とルーティング・フィルター用の内部値は維持する。

## 対象

- `src/components/GalleryModal.tsx`
- `src/components/GalleryModal.test.tsx`
- `src/types/catalogue.ts`
- `src/locales/ja.ts`
- 必要に応じた日本語化テスト

## 実装方針

1. 既存テストを日本語の期待値へ更新し、未実装の状態で失敗を確認する。
2. `jaMessages.catalogue` と件数用formatterを追加する。
3. カタログの固定UI、状態表示、ツールチップ、投稿案内、閉じる操作を翻訳カタログへ接続する。
4. `CATEGORY_LABELS` の表示値だけを日本語化し、カテゴリキーは変更しない。
5. fetch失敗は日本語の説明にHTTP状態を含め、外部由来データはそのまま表示する。
6. 検索、ソース/カテゴリ絞り込み、読込、デザイナー遷移、RDF表示、埋め込みコードコピーの回帰をテストする。

## TDD手順

1. `GalleryModal.test.tsx` の既存期待値を日本語化し、見出し・アクセシブル名・カテゴリ表示の検証を追加する。
2. 対象テストを実行してREDを確認する。
3. 最小限の翻訳カタログとコンポーネント変更を実装する。
4. 対象テストと `npm run qa:ja` をGREENにする。
5. 対象ファイルのESLint、全テスト、buildを実行する。

## 非対象

- カタログエントリの名前、説明、タグ、author、RDF内容
- カタログID、source/category値、URLパラメータ、埋め込みコード
- 学習記事本文、AIビルダー、埋め込みウィジェット
- カタログの検索・ルーティング仕様変更

- Issue #15 の受け入れ条件を満たす。
- 翻訳検査、対象テスト、全テスト、本番buildが成功する。
